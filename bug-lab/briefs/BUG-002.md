# Brief BUG-002: order list

**Area:** the Orders list (retailer and staff), including paging and page size.

**Rule to verify (overview §7):**
- Lists are filtered and paginated on the server, with a default page size of 20 and allowed sizes of 20, 50, and 100.
- Sorting is stable (with a unique tie-breaker).
- Paging through the list shows every matching order exactly once.

**Setup:** `pnpm bug-lab setup --defect BUG-002`, then `pnpm bug-lab start --run …`. The scenario gives Tabletop Lantern 45 orders. Also prepare a `none` run to compare.

**Suggested charter:** as `retailer@tabletop-lantern.test`, page through the orders with different page sizes and filters. Compare the order numbers on each page against the full list (page size 100).

**Deliver:** a defect report with exact steps, the order numbers you expected and saw on each page, the run manifest, and your assessment of impact.
