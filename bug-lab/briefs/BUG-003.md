# Brief BUG-003: submitted order prices

**Area:**
- the order detail page for submitted orders;
- catalog price management (administrator).

**Rule to verify (overview §4):**
- Submitting an order freezes each line's SKU, product name, language, edition, unit price, and line total, and the order total.
- Later catalog edits never change that history.
- Draft prices are provisional.

**Setup:** `pnpm bug-lab setup --defect BUG-003`, then `pnpm bug-lab start --run …`. Also prepare a `none` run to compare.

**Suggested charter:**
1. As `admin@pandora.test`, change the price of a SKU that appears on a submitted order. The seeded `PO-000002` contains `CWO-EN-STD`.
2. Reopen that order as the retailer and as staff.
3. Also try a draft order and compare the two.
4. Check whether each line total and the order total agree with each other.

**Deliver:** a defect report with exact steps, expected versus actual values in minor units, the run manifest, and your assessment of impact.
