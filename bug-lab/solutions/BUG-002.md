# Solution BUG-002: page 2 repeats an order and pushes another to the next page

**Symptom:**
- From page 2 onward, each page starts with the last order of the previous page, and the page's own last order is pushed to the next page.
- With 45 Tabletop Lantern orders and page size 20:
  - page 2 shows orders 20–39 (it repeats the 20th and misses the 40th);
  - page 3 shows orders 40–45.
- When the total is an exact multiple of the page size (for example 40), the final order becomes unreachable: the last page ends one order early and there is no next page.
- The total count is correct, which makes the defect easy to miss.

**Cause:** `OrdersService.list` computes the offset as `(page - 1) × pageSize - 1` for pages after the first.

**Fix:** use `(page - 1) × pageSize`.

**Assertion (in `apps/api/checks/bug-lab.mjs`):** page 2 of 20 must equal rows 21–40 of the same list fetched with page size 100.

Bug Lab observes one repeated order (the last one on page 1) and one missing order.
