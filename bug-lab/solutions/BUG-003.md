# Solution BUG-003: submitted order shows current catalog prices

**Symptom:**
- After a catalog price change, a submitted, confirmed, or shipped order shows the new unit price, and a line total computed from it.
- The order total still shows the frozen value, so the page no longer adds up.
- Draft orders correctly show provisional current prices, which hides the difference.

**Cause:**
- The order line mapping in `OrdersService` (`lineDto`) reads the variant's current `unitPriceMinor` for frozen lines instead of the snapshot columns.
- The database snapshot is untouched, which proves the defect is on the read path.

**Fix:** frozen lines always use `order_lines.unit_price_minor` and `line_total_minor`.

**Assertion (in `apps/api/checks/bug-lab.mjs`):**
1. Raise the catalog price of `CWO-EN-STD` by 500 minor units.
2. Reopen `PO-000002`.
3. Expect the submitted unit price, line total, and order total to be unchanged.

Bug Lab shows the new catalog price, and the stored snapshot still holds the submitted price.
